## 1) ภาพรวมและฐานกฎหมาย

### ความสำคัญ
ชุดเรียนนี้เน้น**เอกสารที่ ก.ศ. ออก** (ระเบียบ ประกาศ คำสั่ง) ภายใต้อำนาจตาม พ.ร.บ.ระเบียบบริหารราชการศาลยุติธรรม พ.ศ. 2543  
ก.ศ. เป็นองค์กร**บริหารงานบุคคล**ของข้าราชการศาลยุติธรรม (ฝ่ายธุรการ) — คล้าย **ก.พ.** ของระบบพลเรือน

### ฐานกฎหมายหลัก

| มาตรา | เนื้อหา |
|-------|---------|
| **ม.18** | องค์ประกอบ ก.ศ. |
| **ม.19–20** | วาระ การพ้นจากตำแหน่ง องค์ประชุม |
| **ม.21** | อำนาจหน้าที่ ก.ศ. |

### การแก้ไขสำคัญ: ฉบับที่ 3 พ.ศ. 2558

| รายการ | เนื้อหา |
|--------|---------|
| ประกาศ | 8 ก.ย. 2558 · เล่ม 132 ตอนที่ 86 ก |
| ใช้บังคับ | วันถัดจากวันประกาศ → **9 ก.ย. 2558** |
| สาระ | แก้ **ม.18** องค์ประกอบ ก.ศ. |
| จุดจำ | ประธาน ก.ศ. = **ประธานศาลอุทธรณ์** (ไม่ใช่รองประธานศาลฎีกาอาวุโสสูงสุดอีกต่อไป) |

## 2) ก.ศ. คืออะไร — ขอบเขตอำนาจ

### ชื่อเต็ม
**คณะกรรมการข้าราชการศาลยุติธรรม** (ย่อ **ก.ศ.**)

### ขอบเขตอำนาจ — จุดสำคัญ

| อยู่ในอำนาจ ก.ศ. | ไม่อยู่ในอำนาจ ก.ศ. |
|-----------------|-------------------|
| **ข้าราชการศาลยุติธรรม** (ฝ่ายธุรการ) | **ข้าราชการตุลาการ** (ผู้พิพากษา) → **ก.ต.** |
| สรรหา บรรจุ แต่งตั้ง โอน เลื่อน | การแต่งตั้ง/วินัยผู้พิพากษา |
| วินัย สอบสวน ลงโทษ อุทธรณ์ | อำนาจพิพากษาคดี |
| สวัสดิการ เงินเดือน ลา กองทุน | นโยบายบริหารราชการทั่วไป → **ก.บ.ศ.** |
| เครื่องแบบ จ้างผู้เชี่ยวชาญ | งบประมาณภาพรวม → **ก.บ.ศ.** |

**จำสั้น:** ก.ศ. = HR ของ**ข้าราชการศาล (ธุรการ)** · ผู้พิพากษา = **ก.ต.**

## 3) องค์ประกอบ ก.ศ. (ม.18 หลังแก้ฉบับที่ 3)

### องค์ประกอบ (ม.18)

| ลำดับ | กรรมการ | รายละเอียด |
|-------|---------|-----------|
| 1 | **ประธานศาลอุทธรณ์** | เป็นประธานกรรมการ *(เปลี่ยนจากเดิมหลังฉบับที่ 3)* |
| | รองประธานศาลฎีกาซึ่งมีอาวุโสสูงสุด | กรรมการโดยตำแหน่ง |
| | **เลขาธิการ ก.พ.** | กรรมการโดยตำแหน่ง |
| | **เลขาธิการสำนักงานศาลยุติธรรม** | กรรมการโดยตำแหน่ง |
| 2 | ข้าราชการตุลาการ | ได้รับแต่งตั้งจาก**คณะกรรมการตุลาการศาลยุติธรรม (ก.ต.)** **ชั้นศาลละ 1 คน** |
| 3 | ข้าราชการศาลยุติธรรม | ได้รับเลือก **5 คน** (ตามประเภท/ระดับตำแหน่งที่กฎหมายกำหนด ยกเว้นเลขาธิการ) |
| 4 | ผู้ทรงคุณวุฒิ | ด้านพัฒนาองค์กร / บริหารงานบุคคล / บริหารจัดการ ไม่เกิน **3 คน** |

- ก.ศ. แต่งตั้งข้าราชการศาลยุติธรรมเป็น**เลขานุการ**และ**ผู้ช่วยเลขานุการ**

### เปรียบเทียบองค์ประกอบ ก.บ.ศ. vs ก.ศ.

| เรื่อง | ก.บ.ศ. | ก.ศ. |
|--------|--------|------|
| ประธาน | **ประธานศาลฎีกา** | **ประธานศาลอุทธรณ์** |
| ตุลาการต่อชั้น | **4 คน**/ชั้น | **1 คน**/ชั้น (จาก ก.ต.) |
| ข้าราชการศาล | — (ไม่มีใน ก.บ.ศ.) | **5 คน** (เลือก) |
| ผู้ทรงคุณวุฒิ | **2–4 คน** (อายุ 40+) | ไม่เกิน **3 คน** |
| เลขาธิการ ก.พ. | — | **มี** (โดยตำแหน่ง) |
| เลขาธิการสำนักงาน | เลขานุการ | **กรรมการ** (โดยตำแหน่ง) |

### วาระและองค์ประชุม

| เรื่อง | หลัก |
|--------|------|
| วาระ (ม.19) | **2 ปี** · ดำรงเกิน **2 วาระติดต่อกัน** ไม่ได้ |
| องค์ประชุม (ม.20) | ไม่น้อยกว่า**กึ่งหนึ่ง** · เสียงข้างมาก · เสียงเท่ากันประธานชี้ขาด |

## 4) อำนาจหน้าที่ ก.ศ. (ม.21)

### อำนาจหลัก — ออกระเบียบ/ประกาศเกี่ยวกับการบริหารงานบุคคล

ก.ศ. มีอำนาจออกระเบียบหรือประกาศเกี่ยวกับ**การบริหารงานบุคคล**ของสำนักงานศาลยุติธรรม เช่น

| หมวด | รายการ |
|------|--------|
| **สรรหาและบรรจุ** | คุณสมบัติ · คัดเลือก · บรรจุ · แต่งตั้ง · ทดลองงาน |
| **การดำรงตำแหน่ง** | พัฒนา · ย้าย · โอน · เลื่อนตำแหน่ง · เลื่อนเงินเดือน |
| **การพ้นตำแหน่ง** | พ้นจากตำแหน่ง · ออกจากราชการ · พักราชการ · ให้ออกไว้ก่อน |
| **วินัย** | วินัย · สอบสวน · ลงโทษ · ร้องทุกข์ · **อุทธรณ์** |
| **การปฏิบัติราชการ** | รักษาราชการแทน · ปฏิบัติราชการแทน |
| **เครื่องแบบ** | เครื่องแบบและการแต่งกาย |
| **ผู้เชี่ยวชาญ** | จ้างผู้เชี่ยวชาญ/ผู้ชำนาญการและค่าตอบแทน |
| **สวัสดิการ** | สวัสดิการ · ทะเบียนประวัติ · เกษียณอายุ |
| **ลูกจ้าง** | การจ้างลูกจ้าง |

**จำสั้น:** ก.ศ. = ทุกเรื่อง**คน** (ยกเว้นผู้พิพากษา)

### อำนาจเสริมที่เกี่ยวข้อง (จาก พ.ร.บ.2543)

| มาตรา | เนื้อหา |
|-------|---------|
| **ม.7** | ก.ศ. กำหนดจำนวนและระดับเจ้าหน้าที่ประจำศาล (โดยความเห็นชอบประธานศาลฎีกา) |
| **ม.24** | นำ พ.ร.บ.ข้าราชการพลเรือน 2551 มาใช้โดยอนุโลม — ก.ศ. = ก.พ. · สำนักงานศาล = กระทรวง · เลขาธิการ = ปลัดกระทรวง |

## 5) กระบวนการออกระเบียบ/ประกาศ ก.ศ.

### ขั้นตอนบังคับ (ม.21 วรรคสุดท้าย)

```
ก.ศ. ร่างระเบียบ/ประกาศ
        ↓
ได้รับความเห็นชอบจาก **ก.บ.ศ.**
        ↓
ประกาศใน**ราชกิจจานุเบกษา**
        ↓
จึง**ใช้บังคับได้**
```

### เปรียบเทียบกับ ก.บ.ศ.

| เรื่อง | ก.บ.ศ. | ก.ศ. |
|--------|--------|------|
| ออกระเบียบ | อำนาจโดยตรง (ม.17) | ต้อง **ก.บ.ศ. เห็นชอบ** |
| ประกาศราชกิจจา | บางเรื่อง (เช่น โครงสร้างสำนักงาน ม.5) | **ระเบียบ/ประกาศ ก.ศ. ต้องประกาศราชกิจจา** |
| ลำดับชั้น | ระเบียบ > ประกาศ > คำสั่ง/มติ | ระเบียบ ก.ศ. อยู่ภายใต้นโยบาย ก.บ.ศ. |

### ตัวอย่างระเบียบ/ประกาศ ก.ศ. ที่มักออกสอบ

- ระเบียบว่าด้วยการสอบคัดเลือกและบรรจุข้าราชการศาลยุติธรรม  
- ระเบียบว่าด้วยวินัยข้าราชการศาลยุติธรรม  
- ระเบียบว่าด้วยเครื่องแบบข้าราชการศาลยุติธรรม  
- ระเบียบว่าด้วยสวัสดิการและสิทธิประโยชน์  
- ประกาศเกี่ยวกับการประเมินผลการปฏิบัติราชการ

## 6) เปรียบเทียบ ก.ศ. ≈ ก.พ. ของศาล

### ตารางเทียบระบบพลเรือน ↔ ระบบศาล

| หน้าที่ | ระบบพลเรือน | ระบบศาลยุติธรรม |
|---------|-------------|-----------------|
| องค์กรกลาง HR | **ก.พ.** | **ก.ศ.** |
| องค์กรกำกับนโยบาย | คณะรัฐมนตรี / กระทรวง | **ก.บ.ศ.** |
| หน่วยงานต้นสังกัด | กระทรวง / กรม | **สำนักงานศาลยุติธรรม** |
| หัวหน้าหน่วยงาน | ปลัดกระทรวง | **เลขาธิการสำนักงานศาลยุติธรรม** |
| พิทักษ์คุณธรรม | **ก.พ.ค.** | (ไม่มีเทียบเท่าโดยตรง) |
| กฎหมายหลัก | พ.ร.บ.ข้าราชการพลเรือน 2551 | พ.ร.บ.บริหารราชการศาล 2543 + อนุโลม พ.ร.บ.2551 (ม.24) |
| เว็บเผยแพร่ระเบียบ | ocsc.go.th | **ojoc.coj.go.th** |

### หลัก ม.24 — อนุโลม พ.ร.บ.2551

| คำใน พ.ร.บ.2551 | ให้หมายถึง (ในระบบศาล) |
|----------------|----------------------|
| ก.พ. | **ก.ศ.** |
| กระทรวง | **สำนักงานศาลยุติธรรม** |
| ปลัดกระทรวง | **เลขาธิการสำนักงานศาลยุติธรรม** |

## 7) ความสัมพันธ์กับ ก.บ.ศ. และ ก.ต.

### ก.ศ. ↔ ก.บ.ศ.

| เรื่อง | ความสัมพันธ์ |
|--------|-------------|
| ระเบียบ ก.ศ. | ต้อง **ก.บ.ศ. เห็นชอบ** + ราชกิจจา |
| นโยบายบริหาร | **ก.บ.ศ.** กำหนด · ก.ศ. ปฏิบัติในกรอบงานบุคคล |
| งบประมาณ | ก.ศ. เสนอผ่านสำนักงาน → **ก.บ.ศ.** เห็นชอบ |
| แต่งตั้งรองเลขาธิการ | เลขาธิการเสนอ → **ก.ศ.** เห็นชอบ (ฟังความเห็น **ก.บ.ศ.**) → ประธานศาลฎีกาสั่งบรรจุ (ม.22) |

### ก.ศ. ↔ ก.ต.

| เรื่อง | ก.ศ. | ก.ต. |
|--------|------|------|
| ข้าราชการศาลยุติธรรม (ธุรการ) | **ดูแล** | — |
| ข้าราชการตุลาการ (ผู้พิพากษา) | — | **ดูแล** |
| กรรมการใน ก.ศ. จากตุลาการ | ชั้นศาลละ **1 คน** (แต่งตั้งโดย **ก.ต.**) | แต่งตั้ง |
| วินัยเลขาธิการ | — | **ก.ต.** ดำเนินการได้ (ม.22) |

## 10) แผนจำเร็วก่อนสอบ

### 10 ข้อท่องก่อนเข้าห้องสอบ

1. **ก.ศ.** = คณะกรรมการ**ข้าราชการ**ศาลยุติธรรม · ฐาน **ม.18 + ม.21**  
2. ประธาน = **ประธานศาลอุทธรณ์** (หลังฉบับที่ 3 ปี 2558)  
3. โดยตำแหน่ง: รองประธานฎีกาอาวุโสสูงสุด · เลขาธิการ **ก.พ.** · เลขาธิการ**สำนักงาน**  
4. ตุลาการ **1/ชั้น** (จาก ก.ต.) · ข้าราชการศาล **5 คน** · ผู้ทรงคุณวุฒิ ≤ **3 คน**  
5. วาระ **2 ปี** · องค์ประชุม **กึ่งหนึ่ง**  
6. อำนาจ = สรรหา บรรจุ วินัย สวัสดิการ เครื่องแบบ จ้างผู้เชี่ยวชาญ  
7. **ไม่ดูแลผู้พิพากษา** → ก.ต.
