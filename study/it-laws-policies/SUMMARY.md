## 1) ภาพรวมและความสัมพันธ์กับศาล e-justice

### ความสำคัญ
กฎหมาย IT ทั่วไปเป็น**กรอบพื้นฐาน**ที่ศาลอิเล็กทรอนิกส์ต้องปฏิบัติตาม  
ข้อกำหนดประธานศาลฎีกา 2563 อ้างอิงและเชื่อมโยงกับกฎหมายเหล่านี้

### แผนภาพความเชื่อมโยง

```
พ.ร.บ.ธุรกรรมฯ 2544 ──→ เอกสาร/e-sign ในศาล (ข้อกำหนด 2563 ข้อ 9–12)
PDPA 2562 ──────────→ ข้อมูลคู่ความ/พยาน/เจ้าหน้าที่
Cybersecurity 2562 ─→ ข้อ 24–25 ข้อกำหนด 2563 · แจ้งเหตุไซเบอร์
พ.ร.บ.คอมพิวเตอร์ 2550 ─→ คุ้มครองระบบสารสนเทศศาล
CIA Triad ──────────→ หลักออกแบบระบบ e-Filing
```

## 2) พ.ร.บ.ธุรกรรมทางอิเล็กทรอนิกส์ พ.ศ. 2544

### ความสำคัญ
รองรับ**ผลทางกฎหมาย**ของข้อมูลอิเล็กทรอนิกส์และลายมือชื่ออิเล็กทรอนิกส์  
เป็นฐานกฎหมายที่ข้อกำหนดศาล 2563 อ้างอิงในเรื่องเอกสารอิเล็กทรอนิกส์

### จุดจำสำคัญ

| เรื่อง | จำ |
|--------|-----|
| ประกาศ | 2 เมษายน พ.ศ. 2544 |
| หลักสำคัญ | ข้อมูลอิเล็กทรอนิกส์และลายมือชื่ออิเล็กทรอนิกส์**มีผลทางกฎหมาย** |
| เอกสารอิเล็กทรอนิกส์ | เทียบเท่าเอกสารลายลักษณ์ธรรมดา (เมื่อเป็นไปตามที่กฎหมายกำหนด) |
| ลายมือชื่ออิเล็กทรอนิกส์ | ใช้แสดงเจตนาเกี่ยวกับข้อมูลอิเล็กทรอนิกส์ · มีผลเทียบเท่าลายมือชื่อ |

### การแก้ไขเพิ่มเติม
- มีการแก้ไขเพิ่มเติมหลายฉบับ (เช่น ฉบับที่ 2 พ.ศ. 2551, ฉบับที่ 3 พ.ศ. 2559, ฉบับที่ 4 พ.ศ. 2562)  
- ปรับให้สอดคล้องกับเทคโนโลยีและ PDPA

### เชื่อมกับศาล

| บริบทศาล | การใช้ พ.ร.บ.ธุรกรรมฯ |
|----------|----------------------|
| e-Filing | เอกสารยื่นคดีทางอิเล็กทรอนิกส์มีผลทางกฎหมาย |
| ลายมือชื่ออิเล็กทรอนิกส์ | คู่ความ/ทนายลงนามในเอกสารอิเล็กทรอนิกส์ |
| ข้อกำหนด 2563 ข้อ 3 | นิยามอิง พ.ร.บ.ธุรกรรมฯ 2544 |
| ข้อ 11 | ลายมือชื่ออิเล็กทรอนิกส์ตาม พ.ร.บ.ธุรกรรมฯ |

## 3) พ.ร.บ.ว่าด้วยการกระทำความผิดเกี่ยวกับคอมพิวเตอร์ พ.ศ. 2550 (+แก้ 2560)

### ความสำคัญ
กำหนดความผิดทางอาญาเกี่ยวกับระบบคอมพิวเตอร์และข้อมูลอิเล็กทรอนิกส์  
คุ้มครอง**ระบบสารสนเทศของหน่วยงานราชการ** รวมถึงศาล

### จุดจำสำคัญ

| เรื่อง | จำ |
|--------|-----|
| ประกาศฉบับหลัก | พ.ศ. 2550 |
| แก้ไข | พ.ร.บ.แก้ไขเพิ่มเติม (ฉบับที่ 2) พ.ศ. **2560** |
| หน่วยงานกำกับ | กระทรวมดิจิทัลเพื่อเศรษฐกิจและสังคม (เดิม ICT) |

### ความผิดสำคัญ (สรุปแนวสอบ)

| ประเภท | ตัวอย่าง |
|--------|---------|
| เข้าถึงระบบโดยมิชอบ | เข้าถึงคอมพิวเตอร์/ระบบโดยไม่มีสิทธิ |
| แทรกแซงข้อมูล | ทำลาย แก้ไข เปลี่ยนแปลงข้อมูลโดยมิชอบ |
| ไวรัส/มัลแวร์ | ส่งข้อมูลอันเป็นอันตรายต่อระบบคอมพิวเตอร์ |
| ลักทรัพย์ข้อมูล | ทำให้เสียหาย ทำลาย เปลี่ยนแปลงข้อมูล |

### เชื่อมกับศาล
- ระบบ e-Filing และฐานข้อมูลคดีของศาลอยู่ภายใต้การคุ้มครองของ พ.ร.บ.คอมพิวเตอร์  
- การโจมตีระบบศาล = ความผิดตาม พ.ร.บ.คอมพิวเตอร์ + อาจเข้าข่าย Cybersecurity Act

## 4) พ.ร.บ.คุ้มครองข้อมูลส่วนบุคคล พ.ศ. 2562 (PDPA)

### ความสำคัญ
คุ้มครอง**สิทธิเจ้าของข้อมูลส่วนบุคคล** เมื่อมีการเก็บ ใช้ เปิดเผย (ประมวลผล) ข้อมูล  
ศาลต้องปฏิบัติเมื่อเก็บข้อมูลคู่ความ พยาน เจ้าหน้าที่

### หน่วยงานกำกับ
**สำนักงานคณะกรรมการคุ้มครองข้อมูลส่วนบุคคล (สคส. / PDPC)**

### บทบาทสำคัญ

| บทบาท | ความหมาย |
|-------|----------|
| **ผู้ควบคุมข้อมูลส่วนบุคคล** | ผู้กำหนดวัตถุประสงค์และวิธีการในการประมวลผลข้อมูล |
| **ผู้ประมวลผลข้อมูลส่วนบุคคล** | ผู้ประมวลผลตามคำสั่ง/ในนามของผู้ควบคุม |

### มาตราสำคัญที่มักออกสอบ

| มาตรา | หลัก |
|-------|------|
| **ม.19** | โดยหลักต้องได้รับ**ความยินยอม**จากเจ้าของข้อมูลก่อนเก็บ/ใช้/เปิดเผย |
| **ม.22** | เก็บเท่าที่**จำเป็น**ต่อวัตถุประสงค์ · ไม่เก็บเกินความจำเป็น |
| **ม.24** | **ข้อยกเว้น** — เก็บ/ใช้โดยไม่ต้องยินยอมได้ในบางกรณี (เช่น ปฏิบัติตามกฎหมาย · ป้องกันอันตรายต่อชีวิต · ประโยชน์สาธารณะ) |
| **ม.26** | **ข้อมูลอ่อนไหว** (เช่น เชื้อชาติ ศาสนา ประวัติสุขภาพ ข้อมูลชีวภาพ) — ห้ามเก็บเว้นแต่มีข้อยกเว้น |

### ลักษณะการขอความยินยอม (ม.19)

- ชัดเจน อ่านง่าย ไม่หลอกลวง  
- เป็นหนังสือหรือทำผ่านระบบอิเล็กทรอนิกส์ได้  
- **ห้าม**กำหนดเงื่อนไขยินยอมที่ไม่จำเป็นต่อการเข้าทำสัญญา  
- เจ้าของข้อมูล**ถอนความยินยอมได้**เมื่อใดก็ได้

### สิทธิเจ้าของข้อมูล (สรุป)

| สิทธิ | ความหมาย |
|-------|----------|
| เข้าถึง | ขอเข้าถึงข้อมูลส่วนบุคคลของตน |
| แก้ไข | ขอแก้ไขข้อมูลที่ไม่ถูกต้อง |
| ลบ | ขอลบ/ทำลายข้อมูล |
| คัดค้าน | คัดค้านการประมวลผล |
| ถอนยินยอม | ถอนความยินยอมเมื่อใดก็ได้ |

### เชื่อมกับศาล

| บริบท | การปฏิบัติ PDPA |
|--------|----------------|
| ข้อมูลคู่ความใน e-Filing | เก็บตามวัตถุประสงค์ · รักษาความลับ |
| ข้อมูลพยาน | เก็บเท่าที่จำเป็น · มีฐานกฎหมายรองรับ |
| ข้อมูลเจ้าหน้าที่ศาล | ผู้ควบคุมข้อมูล = สำนักงานศาลยุติธรรม |
| แยกจาก พ.ร.บ.ข้อมูลข่าวสารฯ | PDPA = ข้อมูล**ส่วนบุคคล** · ข้อมูลข่าวสารฯ = ข้อมูล**ของราชการ** |

## 5) พ.ร.บ.ว่าด้วยการรักษาความมั่นคงปลอดภัยไซเบอร์ พ.ศ. 2562

### ความสำคัญ
กำหนดมาตรการรักษาความมั่นคงปลอดภัยไซเบอร์ของประเทศ  
หน่วยงานสำคัญ (รวมหน่วยงานราชการ) ต้องมีมาตรการและแจ้งเหตุ

### จุดจำสำคัญ

| เรื่อง | จำ |
|--------|-----|
| ประกาศ | พ.ศ. 2562 (ใช้บังคับ 28 พ.ค. 2562) |
| หน่วยงานกำกับ | สำนักงานคณะกรรมการการรักษาความมั่นคงปลอดภัยไซเบอร์แห่งชาติ (สกมช.) |
| หน่วยงานรัฐ | ต้องจัดให้มี**มาตรการรักษาความมั่นคงปลอดภัยไซเบอร์** |
| เหตุการณ์ไซเบอร์ | ต้อง**แจ้งและจัดการ**เหตุการณ์ตามที่กฎหมายกำหนด |

### มาตรการที่หน่วยงานรัฐต้องมี (สรุปแนว)

- มาตรฐานการรักษาความมั่นคงปลอดภัยไซเบอร์  
- การแจ้งเหตุเมื่อเกิดเหตุการณ์ไซเบอร์  
- การตรวจสอบและประเมินความเสี่ยง  
- การฝึกอบรมเจ้าหน้าที่

### เชื่อมกับศาล

| ข้อกำหนด 2563 | Cybersecurity Act |
|--------------|-------------------|
| ข้อ 24 (สำรองข้อมูล) | มาตรการป้องกันการสูญหาย |
| ข้อ 25 (ความปลอดภัย) | มาตรการรักษาความมั่นคงปลอดภัยไซเบอร์ |
| แจ้งเหตุไซเบอร์ | ตามที่ Cybersecurity Act กำหนด |

## 6) CIA Triad และหลักความปลอดภัยสารสนเทศ

### CIA Triad — ท่องให้ขึ้น

| หลัก | ภาษาอังกฤษ | ความหมาย | ตัวอย่างในศาล |
|------|-----------|----------|-------------|
| **C** | Confidentiality | **ความลับ** — ป้องกันการเข้าถึงโดยไม่ได้รับอนุญาต | ข้อมูลคดี · ข้อมูลคู่ความ · คำพิพากษาก่อนประกาศ |
| **I** | Integrity | **ความถูกต้องสมบูรณ์** — ป้องกันการแก้ไขโดยมิชอบ | เอกสาร e-Filing ไม่ถูกดัดแปลง · hash/checksum |
| **A** | Availability | **ความพร้อมใช้งาน** — ระบบพร้อมให้บริการ | e-Filing ใช้งานได้ · สำรองข้อมูล (ข้อ 24) |

### หลักเสริมที่เกี่ยวข้อง

| หลัก | ความหมาย |
|------|----------|
| Authentication | ยืนยันตัวตนผู้ใช้ระบบ |
| Authorization | กำหนดสิทธิเข้าถึงตามบทบาท |
| Non-repudiation | ป้องกันปฏิเสธการกระทำ (เชื่อมกับลายมือชื่ออิเล็กทรอนิกส์) |
| Audit trail | บันทึกการเข้าถึง/แก้ไขข้อมูลตรวจสอบย้อนกลับได้ |

## 7) รัฐบาลดิจิทัล / e-Service

### หลักการบริการภาครัฐดิจิทัล (สรุปแนวสอบ)

| หลัก | เนื้อหา |
|------|---------|
| บริการออนไลน์ | ประชาชนเข้าถึงบริการราชการผ่านช่องทางดิจิทัล |
| ข้อมูลเชื่อมโยง | หน่วยงานแชร์ข้อมูลภายใต้กรอบกฎหมาย (PDPA) |
| ความปลอดภัย | มาตรการรักษาความมั่นคงปลอดภัยไซเบอร์ |
| ความเท่าเทียม | บริการดิจิทัลต้องเทียบเท่าบริการปกติ (เชื่อม ข้อกำหนด 2563 ข้อ 5) |
| เปิดเผยข้อมูล | ตาม พ.ร.บ.ข้อมูลข่าวสารของราชการ พ.ศ. 2540 |

### เชื่อมกับศาล
- ศาล e-justice เป็นส่วนหนึ่งของ**ยุติธรรมดิจิทัล**  
- e-Filing = e-Service สำหรับคู่ความ  
- ต้องปฏิบัติตามกรอบ IT ทั่วไป + ข้อกำหนดเฉพาะศาล 2563

## 8) ความเชื่อมโยงกับศาลอิเล็กทรอนิกส์

### ตารางเชื่อมโยงครบ

| กฎหมาย IT | ใช้ในศาล e-justice อย่างไร | ข้อกำหนด 2563 |
|-----------|---------------------------|--------------|
| พ.ร.บ.ธุรกรรมฯ 2544 | เอกสาร/e-sign มีผลทางกฎหมาย | ข้อ 3, 9–12 |
| พ.ร.บ.คอมพิวเตอร์ 2550 | คุ้มครองระบบสารสนเทศศาล | — |
| PDPA 2562 | คุ้มครองข้อมูลคู่ความ/พยาน | — |
| Cybersecurity 2562 | มาตรการความปลอดภัย · แจ้งเหตุ | ข้อ 24–25 |
| CIA Triad | ออกแบบระบบ e-Filing | ข้อ 24–25 |

### การใช้ IT ของเจ้าหน้าที่ราชการ/ศาล (แนวปฏิบัติ)

- ใช้อีเมล/ระบบราชการอย่างถูกต้อง · ไม่เปิดเผยความลับ  
- ปฏิบัติตาม PDPA เมื่อเก็บข้อมูลส่วนบุคคล  
- รายงานเหตุไซเบอร์ตาม Cybersecurity Act  
- ปฏิบัติตามข้อกำหนด 2563 และประกาศสำนักงานเมื่อใช้ระบบศาล

## 9) ตารางจำสอบ (Exam Memory Tables)

### ตาราง 1: กฎหมาย IT หลัก

| กฎหมาย | ปี | จำคำเดียว |
|--------|-----|----------|
| พ.ร.บ.ธุรกรรมฯ | **2544** | เอกสาร/e-sign |
| พ.ร.บ.คอมพิวเตอร์ | **2550** (+แก้ **2560**) | ความผิดคอม |
| PDPA | **2562** | ข้อมูลส่วนบุคคล |
| Cybersecurity Act | **2562** | ไซเบอร์ |

## 10) กับดักข้อสอบที่พบบ่อย

## 11) แผนจำเร็วก่อนสอบ

### 10 ข้อท่องก่อนเข้าห้องสอบ

1. **2544** = ธุรกรรมอิเล็กทรอนิกส์ · เอกสาร/e-sign มีผลทางกฎหมาย  
2. **2550/2560** = ความผิดคอมพิวเตอร์ · คุ้มครองระบบสารสนเทศ  
3. **2562** = PDPA + Cybersecurity (คนละเรื่อง · ปีเดียวกัน)  
4. PDPA: ม.19 = **ยินยอม** · ม.22 = **จำเป็น** · ม.24 = **ข้อยกเว้น** · ม.26 = **อ่อนไหว**  
5. PDPC = หน่วยกำกับ PDPA  
6. Cybersecurity = มาตรการความปลอดภัย · **แจ้งเหตุ**ไซเบอร์  
7. CIA: **C**=ลับ · **I**=ถูกต้อง · **A**=พร้อมใช้  
8. ศาล e-justice เชื่อม: ธุรกรรมฯ → เอกสาร · PDPA → ข้อมูลคน · Cyber → ข้อ 24–25  
9. ข้อมูลข่าวสารฯ (ราชการ) ≠ PDPA (ส่วนบุคคล)  
10. ข้อ 18 2563 = ห้ามปฏิเสธหลักฐานอิเล็กทรอนิกส์
