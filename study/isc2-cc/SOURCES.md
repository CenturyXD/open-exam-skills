## รูปแบบข้อสอบ (สรุปจาก Official Outline)

- ความยาว: **2 ชั่วโมง**
- จำนวนข้อ: **100–125**
- รูปแบบ: Multiple choice และ advanced item types
- คะแนนผ่าน: **700 จาก 1000**
- ภาษา: English, Chinese, Japanese, German, Spanish
- สถานที่: Pearson VUE Testing Center
- ประสบการณ์: **ไม่มี prerequisite** (แนะนำให้มีพื้นฐาน IT)

## โดเมนปัจจุบัน (ถึงก่อน 1 ก.ย. 2026)

1. Security Principles — 26%
2. Business Continuity (BC), Disaster Recovery (DR) & Incident Response Concepts — 10%
3. Access Controls Concepts — 22%
4. Network Security — 24%
5. Security Operations — 18%

## โดเมนใหม่ (มีผล 1 ก.ย. 2026)

1. Security Principles — 24%
2. Security Governance — 17.3%
3. Identity and Access Management (IAM) Concepts — 20%
4. Networking and Cloud Security Concepts — 21.3%
5. Security Operations and Incident Response — 17.3%

ชุดเรียนนี้จัดตาม **โครงปัจจุบัน (D1)** เป็นหลัก เพราะยังใช้สอบได้ และเนื้อหาส่วนใหญ่ยังทับซ้อนกับ D2 (ย้าย BC/DR ไป Governance, รวม Cloud ชัดขึ้น, รวม IR เข้า Operations)

## ขอบเขตชุดเรียนนี้

ครอบคลุมแนวคิดพื้นฐานที่พบบ่อยใน CC:
1. CIA triad, AAA, non-repudiation, privacy, risk, controls, ethics, governance
2. BC / DR / Incident Response
3. Physical & logical access controls (PoLP, SoD, DAC/MAC/RBAC)
4. Networking (OSI/TCP-IP), threats, IDS/IPS, firewall, segmentation, cloud models
5. Data security, hardening, policies, security awareness

## คำเตือนการใช้งาน

- ชุดนี้เป็นสรุปเพื่อทบทวนสอบ ไม่ใช่ Official ISC² Training และไม่ได้แทน Official Exam Outline
- ก่อนลงทะเบียนสอบ ให้ตรวจ exam outline ฉบับล่าสุดบนเว็บ ISC² เสมอ (โดยเฉพาะช่วงเปลี่ยนโดเมน ก.ย. 2026)
- เนื้อหาเป็นการสรุปแนวคิดมาตรฐานอุตสาหกรรมที่สอดคล้องกับ outline — ไม่คัดลอกข้อสอบจริง
