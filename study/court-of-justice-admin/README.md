# ชุดเรียน: พ.ร.บ.ระเบียบบริหารราชการศาลยุติธรรม พ.ศ. 2543 และที่แก้ไขเพิ่มเติม

ชุดทบทวนสอบจากตัวบทและแหล่งราชการ (ราชกิจจานุเบกษา, สำนักงานศาลยุติธรรม)

## ไฟล์ในชุดนี้

| ไฟล์ | คำอธิบาย |
|------|----------|
| `SUMMARY.md` / `summary.html` | **สรุปฉบับละเอียด (เริ่มที่นี่)** |
| `SOURCES.md` | แหล่งอ้างอิง |
| `mindmap.md` / `mindmap.html` | แผนที่ความคิด |
| `flashcards.json` / `flashcards.html` | บัตรคำ 20 ใบ |
| `quiz.json` / `quiz.html` | แบบทดสอบ 2 ชุด ชุดละ 15 ข้อ — เลือกชุดได้ |

## วิธีใช้

0. เปิด [เมนูหลัก](../index.html) แล้วเลือกอันที่ต้องการ
1. อ่าน `summary.html`
2. ดูโครงใน `mindmap.html`
3. ท่องด้วย `flashcards.html`
4. ทดสอบด้วย `quiz.html`
