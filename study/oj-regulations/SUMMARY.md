## 1) ภาพรวมและฐานกฎหมาย

### ความสำคัญ
สำนักงานศาลยุติธรรมเป็น**หน่วยธุรการอิสระ**ของศาลยุติธรรม แยกจากกระทรวงยุติธรรม  
ชุดเรียนนี้เน้น**ประกาศปฏิบัติการ**ที่สำนักงานออก — โดยเฉพาะรายละเอียดการดำเนินงานศาลอิเล็กทรอนิกส์ตามข้อกำหนดประธานศาลฎีกา พ.ศ. 2563

### ฐานกฎหมายหลัก

| มาตรา | เนื้อหา |
|-------|---------|
| **ม.5** | สถานะนิติบุคคล · โครงสร้างโดยประกาศ ก.บ.ศ. |
| **ม.6** | อำนาจหน้าที่หลัก |
| **ม.7** | เจ้าหน้าที่ประจำศาล |
| **ม.8** | เลขาธิการ |
| **ม.9** | ข้าราชการศาลยุติธรรมที่ประจำศาล |
| **ม.32** | งบประมาณ |

### ข้อกำหนดประธานศาลฎีกาที่เกี่ยวข้อง
- **ข้อกำหนดประธานศาลฎีกาว่าด้วยวิธีพิจารณาคดีทางอิเล็กทรอนิกส์ พ.ศ. 2563**  
- สำนักงานออก**ประกาศรายละเอียด**ตาม **ข้อ 27** ของข้อกำหนดดังกล่าว

## 2) สถานะนิติบุคคลและโครงสร้าง (ม.5–8)

### สถานะ (ม.5)

| เรื่อง | รายละเอียด |
|--------|-----------|
| สถานะ | ส่วนราชการที่เป็น**หน่วยงานอิสระ มีฐานะเป็นนิติบุคคล** |
| แยกจาก | กระทรวงยุติธรรม |
| โครงสร้างภายใน | กำหนดโดย**ประกาศ ก.บ.ศ.** เมื่อได้รับความเห็นชอบจาก**ประธานศาลฎีกา** และประกาศใน**ราชกิจจานุเบกษา** แล้วจึงใช้บังคับได้ |

**จำสั้น:** นิติบุคคลอิสระ · โครงสร้างโดย **ประกาศ ก.บ.ศ.** + เห็นชอบประธานศาลฎีกา + ราชกิจจา

### เลขาธิการสำนักงานศาลยุติธรรม (ม.8)

| เรื่อง | รายละเอียด |
|--------|-----------|
| สถานะ | ข้าราชการศาลยุติธรรม |
| ขึ้นตรงต่อ | **ประธานศาลฎีกา** |
| หน้าที่หลัก | ควบคุมดูแลราชการของสำนักงานให้เป็นไปตามกฎหมาย ระเบียบ และ**มติ ก.บ.ศ.** |
| บังคับบัญชา | ข้าราชการในสำนักงาน (มีรองเลขาธิการเป็นผู้ช่วย) |
| ตัวแทนภายนอก | ในกิจการที่เกี่ยวกับบุคคลภายนอก → เลขาธิการเป็น**ผู้แทน**ของสำนักงานศาลยุติธรรม (มอบหมายผู้อื่นแทนได้ตามระเบียบ ก.บ.ศ.) |

### ข้าราชการศาลยุติธรรมที่ประจำศาล (ม.9)

- ต้องปฏิบัติตามคำสั่งของ**ผู้พิพากษา**ในศาลนั้น ซึ่งสั่งในหน้าที่โดยชอบ  
- การเลื่อนขั้นเงินเดือนประจำปีและการแต่งตั้ง ต้องสอดคล้องกับผลการประเมินที่**ผู้พิพากษาหัวหน้าศาล**จัดทำ

## 3) อำนาจหน้าที่หลัก (ม.6–9)

### อำนาจหน้าที่ (ม.6)

สำนักงานศาลยุติธรรมมีอำนาจหน้าที่ดังนี้:
1. **งานธุรการศาลยุติธรรม**  
2. **งานส่งเสริมงานตุลาการ**  
3. **งานวิชาการ**  

เพื่อสนับสนุนและอำนวยความสะดวกให้การพิจารณาพิพากษาคดีสะดวก รวดเร็ว มีประสิทธิภาพ

### เจ้าหน้าที่ประจำศาล (ม.7)

- ต้องจัดเจ้าหน้าที่ประจำศาลทุกแห่งให้เพียงพอ (ธุรการ / ช่วยค้นคว้าวิชาการ / ประสานงาน)  
- จำนวนและระดับเจ้าหน้าที่เป็นไปตามที่ **ก.ศ.** กำหนดโดยความเห็นชอบของประธานศาลฎีกา  
- ถ้าเจ้าหน้าที่เพียงพอ ก.บ.ศ. โดยความเห็นชอบประธานศาลฎีกา อาจประกาศตั้ง**สำนักงานประจำศาล** ได้

### สรุปบทบาทสำนักงาน

```
สำนักงานศาลยุติธรรม = หน่วย "ปฏิบัติการ"
    ├── ธุรการศาล (รับ-ส่งเอกสาร จัดเก็บ สารบรรณ)
    ├── ส่งเสริมงานตุลาการ (อบรม สนับสนุน)
    ├── งานวิชาการ (ค้นคว้า จัดทำเอกสาร)
    └── ศาลอิเล็กทรอนิกส์ (e-Filing ระบบ IT)
```

## 4) งบประมาณและความสัมพันธ์กับ ก.บ.ศ. (ม.32)

### กระบวนการงบประมาณ (ม.32)

```
สำนักงานศาลยุติธรรม เสนองบประมาณรายจ่าย
        ↓
ต่อ **คณะรัฐมนตรี** (เพื่อจัดสรรเป็นเงินอุดหนุนศาลยุติธรรมและสำนักงาน)
        ↓
จัดไว้ในร่าง **พ.ร.บ.งบประมาณ**
        ↓
**ก.บ.ศ.** ให้ความเห็นชอบงบประมาณ (ม.17(3))
```

- คณะรัฐมนตรีอาจทำความเห็นประกอบได้ และอาจเรียกเลขาธิการมาชี้แจงได้

### ความสัมพันธ์ ก.บ.ศ. ↔ สำนักงาน

| ระดับ | หน่วยงาน | บทบาท |
|-------|---------|--------|
| นโยบาย | **ก.บ.ศ.** | กำหนดนโยบาย ออกระเบียบ/ประกาศ กำกับงบประมาณ · **ยับยั้ง**การบริหารที่ไม่ถูกต้อง |
| ปฏิบัติการ | **สำนักงานศาลยุติธรรม** | ดำเนินงานตามนโยบาย/ระเบียบ/มติ ก.บ.ศ. · เลขาธิการควบคุมดูแล |
| งานบุคคล | **ก.ศ.** | บรรจุ วินัย สวัสดิการ ข้าราชการศาล |

## 5) ศาลอิเล็กทรอนิกส์ — ข้อกำหนดประธานศาลฎีกา 2563

### ภาพรวม

| เรื่อง | จำ |
|--------|-----|
| ชื่อเต็ม | ข้อกำหนดประธานศาลฎีกาว่าด้วยวิธีพิจารณาคดีทางอิเล็กทรอนิกส์ พ.ศ. 2563 |
| ประกาศราชกิจจา | **30 ก.ย. 2563** เล่ม 137 ตอนที่ 78 ก |
| ผลใช้บังคับ | **วันถัดจากวันประกาศ** |
| ฐานกฎหมาย | ป.พ.พ. **ม.34/1** · ม.51 วรรคสอง · ม.68 (แก้ไขเพิ่มเติม 28/2558) |
| ผู้รักษาการ | **ประธานศาลฎีกา** (ข้อ 30) |

### โครงสร้างข้อกำหนด 2563 (ภาพรวม)

| หมวด | ข้อ | เนื้อหา |
|------|-----|---------|
| บททั่วไป | 1–3 | ชื่อ ผลใช้บังคับ นิยาม |
| หลักทั่วไป | **4–8** | หลักและขอบเขตการพิจารณาทางอิเล็กทรอนิกส์ |
| เอกสารอิเล็กทรอนิกส์ | 9–12 | การยื่น รับ ส่ง เอกสาร |
| การพิจารณา | **13–14** | นัดพิจารณา/ประชุมทางอิเล็กทรอนิกส์ |
| พยานหลักฐาน | 15–18 | หลักฐานอิเล็กทรอนิกส์ (ห้ามปฏิเสธเพราะเป็นอิเล็กทรอนิกส์) |
| คำพิพากษา | 19 | คำพิพากษา/คำสั่งทางอิเล็กทรอนิกส์ |
| อุทธรณ์/ฎีกา | 20–22 | ประชุมอุทธรณ์/ฎีกาทางอิเล็กทรอนิกส์ |
| ความปลอดภัย | 24–25 | สำรองข้อมูล · ความมั่นคงปลอดภัย |
| ประกาศสำนักงาน | **27** | สำนักงานออกประกาศรายละเอียด |
| บทเฉพาะกาล | 29–30 | ผู้รักษาการ |

### ข้อกำหนด e-Filing รุ่นก่อน
- มีข้อกำหนด e-filing **พ.ศ. 2560** — พัฒนาต่อเป็นข้อกำหนด **2563** ที่ครอบคลุมกว้างขึ้น (ทั้งพิจารณา พยานหลักฐาน ความปลอดภัย)

## 6) ประกาศปฏิบัติการสำนักงาน (ข้อ 4 · 7 · 13 · 27)

### หลักการ: ข้อกำหนด 2563 กำหนดกรอบ · สำนักงานกำหนดรายละเอียด

ข้อกำหนดประธานศาลฎีกา 2563 กำหนดหลักการในระดับกฎหมาย  
**สำนักงานศาลยุติธรรม** ออก**ประกาศปฏิบัติการ**กำหนดรายละเอียดตาม **ข้อ 27**

### ข้อที่มักออกสอบ — สรุปบทบาท

| ข้อ (2563) | หัวข้อ | สำนักงานออกประกาศเรื่อง |
|-----------|--------|------------------------|
| **ข้อ 4** | **หลักและขอบเขต**การพิจารณาคดีทางอิเล็กทรอนิกส์ | รายละเอียดขอบเขตการดำเนินการ · ศาล/คดีที่ใช้ระบบ · เงื่อนไขทั่วไป |
| **ข้อ 7** | การ**ยื่นคำร้อง/เอกสาร**ทางอิเล็กทรอนิกส์ | ขั้นตอน e-Filing · รูปแบบไฟล์ · การชำระค่าธรรมเนียม · การยืนยันตัวตน |
| **ข้อ 13** | การ**นัดพิจารณา/ประชุม**ทางอิเล็กทรอนิกส์ | ระบบประชุมทางไกล · การแจ้งนัด · การเข้าร่วม · การบันทึก |
| **ข้อ 27** | อำนาจสำนักงานออก**ประกาศรายละเอียด** | ฐานอำนาจให้สำนักงานกำหนดรายละเอียดปฏิบัติทั้งหมด |

### ข้อ 4 — หลักและขอบเขต (รายละเอียด)

- กำหนดว่าศาลใด/คดีใดสามารถดำเนินการทางอิเล็กทรอนิกส์ได้  
- หลักการเท่าเทียม — การดำเนินการทางอิเล็กทรอนิกส์มีผลเทียบเท่าการดำเนินการทั่วไป  
- ต้องเป็นไปตามมาตรฐานความปลอดภัย (เชื่อมกับ ข้อ 24–25)

### ข้อ 7 — การยื่นเอกสาร (รายละเอียด)

- ยื่นผ่านระบบ **e-Filing** ตามข้อกำหนด  
- เอกสารในรูปแบบอิเล็กทรอนิกส์ + ลายมือชื่ออิเล็กทรอนิกส์ (อิง พ.ร.บ.ธุรกรรมฯ 2544)  
- สำนักงานกำหนดรูปแบบไฟล์ ขนาด วิธีการยื่น และการยืนยันการรับ

### ข้อ 13 — นัดพิจารณา/ประชุม (รายละเอียด)

- ศาลสามารถนัดพิจารณาคดีหรือประชุมทางอิเล็กทรอนิกส์ได้  
- ต้องแจ้งคู่ความล่วงหน้า · จัดให้มีระบบที่เพียงพอ  
- สำนักงานกำหนดรายละเอียดระบบประชุมทางไกล การบันทึก การเข้าถึง

### ข้อ 27 — อำนาจออกประกาศ (รายละเอียด)

- สำนักงานศาลยุติธรรมมีอำนาจออก**ประกาศ**กำหนดรายละเอียดการปฏิบัติตามข้อกำหนด 2563  
- ครอบคลุมทุกเรื่องที่ข้อกำหนดมอบหมายให้กำหนดรายละเอียด  
- ประกาศสำนักงานต้อง**ไม่ขัด**กับข้อกำหนด 2563 และกฎหมายที่เกี่ยวข้อง

## 7) ระบบ e-Filing

### e-Filing คืออะไร
ระบบ**ยื่นคำร้องและเอกสารคดีทางอิเล็กทรอนิกส์** — เป็นส่วนสำคัญของศาลอิเล็กทรอนิกส์ (e-justice)

### องค์ประกอบหลัก

| องค์ประกอบ | รายละเอียด |
|-----------|-----------|
| ฐานกฎหมาย | ข้อกำหนดประธานศาลฎีกา 2563 · ป.พ.พ. ม.34/1 · พ.ร.บ.ธุรกรรมฯ 2544 |
| ผู้ดูแลระบบ | **สำนักงานศาลยุติธรรม** |
| ประกาศรายละเอียด | สำนักงานออกตาม **ข้อ 4, 7, 13, 27** |
| เอกสาร | ข้อมูลอิเล็กทรอนิกส์ + ลายมือชื่ออิเล็กทรอนิกส์ |
| ความปลอดภัย | ข้อ 24 (สำรองข้อมูล) · ข้อ 25 (ความมั่นคงปลอดภัย) |

### ขั้นตอน e-Filing (ภาพรวม)

```
ผู้ใช้บริการลงทะเบียน/ยืนยันตัวตน
        ↓
ยื่นคำร้อง/เอกสารผ่านระบบ e-Filing (ตามประกาศ ข้อ 7)
        ↓
ระบบตรวจสอบรูปแบบ · ลายมือชื่ออิเล็กทรอนิกส์
        ↓
ศาลรับเอกสาร · ออกเลขที่คดี/เลขรับ
        ↓
แจ้งผล · จัดเก็บเอกสารอิเล็กทรอนิกส์ (ข้อ 27)
```

## 8) นโยบาย (ก.บ.ศ.) vs ปฏิบัติการ (สำนักงาน)

### แยกชั้นอำนาจ

| ระดับ | ผู้ออก | ลักษณะเอกสาร | ตัวอย่าง |
|-------|--------|-------------|---------|
| กฎหมาย/ข้อกำหนด | ประธานศาลฎีกา (ราชกิจจา) | ข้อกำหนด 2563 | หลักการพิจารณาอิเล็กทรอนิกส์ |

## 10) แผนจำเร็วก่อนสอบ

### 10 ข้อท่องก่อนเข้าห้องสอบ

1. สำนักงาน = **นิติบุคคลอิสระ** (ม.5) · แยกจากกระทรวงยุติธรรม  
2. เลขาธิการ → **ประธานศาลฎีกา** · ผู้แทนภายนอก (ม.8)  
3. โครงสร้าง = **ประกาศ ก.บ.ศ.** + เห็นชอบประธานศาลฎีกา + ราชกิจจา  
4. อำนาจ ม.6 = ธุรการ · ส่งเสริมตุลาการ · วิชาการ  
5. งบประมาณ ม.32 = เสนอ**คณะรัฐมนตรี** · ก.บ.ศ. เห็นชอบ  
6. ข้อกำหนด **2563** = กรอบกฎหมาย · สำนักงานออกประกาศตาม **ข้อ 27**  
7. ประกาศสำนักงานสำคัญ: **ข้อ 4** (ขอบเขต) · **ข้อ 7** (ยื่นเอกสาร) · **ข้อ 13** (นัด) · **ข้อ 27** (อำนาจออกประกาศ)  
8. **e-Filing** = ยื่นคำร้อง/เอกสารอิเล็กทรอนิกส์ · สำนักงานดูแล  
9. ก.บ.ศ. = นโยบาย · สำนักงาน = ปฏิบัติการ · ก.ศ. = งานบุคคล  
10. ข้อกำหนดก่อนหน้า = e-filing **2560** → พัฒนาเป็น **2563**
