## 3) พ.ร.บ.ระเบียบบริหารราชการศาลยุติธรรม พ.ศ. 2543

→ รายละเอียดเต็ม: [court-of-justice-admin/SUMMARY.md](../court-of-justice-admin/SUMMARY.md)

| จุดจำ | คำตอบ |
|-------|--------|
| ประกาศ / ใช้บังคับ | 21 มิ.ย. 2543 / **20 ส.ค. 2543** (พ้น 60 วัน) |
| มาตรา | **40** มาตรา |
| ผู้รักษาการ | **ประธานศาลฎีกา** |
| ม.3 | ห้ามกระทบ**อำนาจพิพากษา** |
| ม.5 | สำนักงานศาล = **นิติบุคคลอิสระ** |
| เลขาธิการ (ม.8) | ขึ้นตรง**ประธานศาลฎีกา** · ผู้แทนภายนอก |
| ก.บ.ศ. | ประธาน = **ประธานศาลฎีกา** · ตุลาการ **4/ชั้น** · วาระ **2 ปี** |
| ก.ศ. | ประธาน = **ประธานศาลอุทธรณ์** (หลังฉบับที่ 3) · ข้าราชการศาล **5 คน** |
| เลขาธิการ | ประธานฎีกาเสนอ · **ก.ต.** เห็นชอบ · วาระ **2 ปี** |
| ม.24 | อนุโลม พ.ร.บ.2551: ก.ศ.=ก.พ. · สำนักงาน=กระทรวง · เลขาธิการ=ปลัดกระทรวง |
| ฉบับที่ 4 (2562) | ม.17(1/1) **เบี้ยประชุม** · ออกระเบียบภายใน **30 วัน** |
